# Changelog

All notable changes to this project are recorded here. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-11-11

First public pre-release. The skills are in testing; feedback is welcome through issues.

### Added
- `project-companion`: project fact sheet, 64 project documents by process group, document review, next-step guidance, three audience modes.
- `trainer-toolkit`: case studies, exercises, flawed documents with answer keys, model answers, rubrics, session packs, feedback on submissions.
- `pmo-kit`: standards sheet, template sets, compliance checks, portfolio status report, prioritisation, stage gates, handbook.
- `meeting-to-actions`: decisions, actions, risks and issues, open questions and follow-up message from meeting notes.
- `project-rescue`: diagnosis, gap sizing, options, recovery plan and sponsor brief for a project in trouble.
- `ai-governance-companion`: AI use inventory, risk assessment, acceptable-use policy, roles, supplier questionnaire, incident process, gap check and roadmap.
- Shared catalog, review checklists and Arabic glossary, with `tools/sync_shared.py` to keep copies identical.
- Test cases for every skill under each skill's `evals/` folder.

### Known limits
- The Arabic glossary is a working list and has not been checked against any certification body's official Arabic terms.
- Test cases have been run by the authors only, not yet by independent users.
